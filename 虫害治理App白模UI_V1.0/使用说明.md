# 虫害治理 App 白模 UI V1.0

依据《虫害治理 App 开发需求文档 V1.0》制作的安卓员工端低保真原型，共 20 个页面。采用黑白灰、文字、线框图标和照片占位，供产品、设计、开发及业务团队评审页面结构和操作流程。

## 打开方式

用 Chrome、Edge 或 Safari 打开本目录的 `index.html`，无需安装依赖。电脑端通过左侧目录切换页面，手机端可以使用页面内导航。顶部支持切换联网／离线演示及打开全部页面总览。

原型为单个自包含 HTML 文件，不依赖远程字体、图片或脚本。页面内容超出手机高度时可以在手机画面内上下滚动。PDF 和 PNG 均为每个页面的首屏快照，完整表单及下面的内容请查看交互原型。

## 建议体验顺序

1. 从工作台进入任务详情，打开签到、服务前确认、静态评估及设施点检。
2. 在风险台账查看整改历史，或进入新增风险；在防治措施中填写处理信息。
3. 从服务总结进入员工签字，勾选确认声明后在签字框内手写。
4. 在客户确认页面打开报告，等待至少 5 秒后返回。填写姓名、主动勾选阅读确认并手写签名；星级评价为选填，未预选分数。
5. 提交后进入同步中心。离线演示时无法同步；切回联网演示并完成双方签字后，可以体验发布成功页面。

表单示例内容会保存在当前浏览器的本地存储中，刷新可恢复；密码不会持久保存。请只使用演示内容，不输入真实客户资料。清除该页面的浏览器站点存储可以重置演示。

## 业务规则呈现

- 服务完成后仍可存在待整改风险，整改台账持续跟进。
- 客户反馈、现场发现和设施捕获分来源展示，不默认合计。
- 设施状态与耗材更换独立填写，未检查和无法确认独立呈现。
- 客户现场确认采用员工先签、客户后签流程，并呈现 5 秒报告阅读限制。
- 离线保存、待同步、改派冲突及报告更正均设置独立的界面提示。
- 正式报告更正需创建新版本并重新双方确认。

## 原型范围

这是界面与交互评审稿，不是已经开发完成的安卓 App。所用门店、人员、数量和报告均为示例；不同页面也可展示流程中的不同时刻。

已演示页面跳转、部分表单保存、任务筛选、手写签字、阅读倒计时、联网状态切换和模拟发布。照片使用占位图，定位为示意。新增应急、新增设施、客户拒签、报告更正和分享等入口提供流程说明弹窗，尚未制作完整的二级表单。

未连接账号系统、真实相机／GPS、服务器、上传服务或正式报告生成服务。原型的本地存储与模拟同步不代表生产级离线可靠性、权限隔离、冲突处理或签字内容锁定已经实现。网页管理后台不在此次 20 页安卓员工端白模范围内。
