# 舍为思虫害治理 App · VI 应用说明

设计依据：用户指定的《舍为思智慧科技网站设计提示词》，并参照同一品牌目录中的《舍为思公司设计风格规范》《舍为思广告与VI图片资料》。附件中的网站示例仅作为视觉参考，本次交付保留虫控员工端的业务流程。

## 色彩

| 角色 | 色值 | 应用位置 |
|---|---|---|
| 品牌主色 | `#003D7A` | 主按钮、标题、导航选中项、签名笔迹 |
| 品牌辅色 | `#4A9FD8` | 进度条、焦点描边、波浪装饰 |
| 主背景 | `#FFFFFF` | 表单、卡片、导航、报告纸面 |
| 次背景 | `#F5F8FA` | 页面底色与作业内容区域 |
| 主文字 | `#333333` | 正文与表单内容 |
| 次文字 | `#666666` | 说明、辅助提示 |

成功和异常使用少量语义色，同时以文字和图标表达状态。浅蓝用于装饰和交互提示；主要正文使用深色，按钮浅蓝悬停时配深色文字。

## Logo与品牌元素

使用用户Obsidian品牌资料 `Attachment/logo 1.png` 中的原始圆形波浪Logo，保持原比例与原配色，已复制至 `src/assets/sheweisi-logo.png`。登录页、原型评审栏、报告及“我的”中均使用该标志。

登录与工作台欢迎区使用淡蓝波浪装饰，浓度控制在约10%—20%，不放在密集表单后方。品牌口号为“提供超出预期的服务”；公司名为“浙江舍为思智慧科技开发有限公司”。网站模板中的地址、电话和营销Hero文案未作为虫控业务默认信息。

## 字体与层级

中文字体栈优先思源黑体、微软雅黑，按平台回退苹方及系统无衬线；英文回退Arial、Helvetica。包内不附字体文件，也不依赖外部字体服务。

- 桌面评审主标题32px，移动区域24px或20px。
- App欢迎标题24px，导航和模块标题18px。
- 业务正文、表单与辅助说明至少14px；手机系统状态栏为模拟系统尺寸。
- 采用8、16、24、40px为主的间距，移动表单保留16px左右边距。

## 组件与移动适配

主按钮深蓝底白字、4px圆角；次按钮深蓝2px边框。常用操作最小44px点击范围。卡片使用8px圆角、白底和轻微蓝灰阴影。图标沿用原型中的本地24px线性图标，统一2px线宽。

移动端顶部导航56px；表单内容独立滚动，底部操作栏固定。桌面为页面目录、390px手机预览和说明栏；小于1200px隐藏右侧说明，小于768px改用下拉页面选择。`?screen=1` 显示全屏手机内容，适合手机浏览器和单页截图。

键盘焦点可见，主要输入有可读标签，状态以文字表达；签名支持鼠标或触屏。减少动态效果，尊重系统减少动画偏好。

## 原型层与产品层

外侧目录、网络演示、填充示例和重置是评审工具；手机内是产品页面。流程、输入字段及重要状态规则沿用虫控需求，品牌视觉只改变呈现。客户确认页只展示当前服务；外围评审工具不属于正式客户操作界面。

正式安卓实现应继续验证设备字体、系统状态栏、相机、定位、签名触控和无障碍支持。本次浏览器检查不能替代安卓真机验收。
