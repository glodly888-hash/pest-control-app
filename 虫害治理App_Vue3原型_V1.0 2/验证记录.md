# 验证记录 · 2026-11-12

测试对象：本次舍为思VI风格的Vue 3员工端原型。运行环境为本机Node.js 22.22.3与Playwright Chromium，未连接业务后端。

| 项目 | 结果 |
|---|---|
| 全量构建 | 20个独立HTML生成成功，每页约134—140KB，内含运行时、样式和Logo |
| Vue开发入口 | 20页全部加载，无Vue运行警告或页面脚本异常 |
| 响应式页面 | 320、768、1024、1440四种宽度共80次加载，无整页或手机内容横向溢出 |
| 单文件断网打开 | 20个HTML以file协议打开成功，无HTTP/CDN资源请求 |
| 手机模式 | `?screen=1`可隐藏评审工具，跨页保持手机模式 |
| 视觉检查 | 检查20页首屏；抽查桌面工作台、登录、设施点检、报告归档的完整尺寸截图 |
| 页面图交付 | 20张首屏PNG、桌面评审视图及6页品牌风格总览 |

## 已通过的12项关键交互

1. 作业缺少内容时，员工签字按钮不可用，并列出补录入口。
2. 完整示例包含9处设施、7条风险，能够通过本机校验。
3. 报告分别显示客户反馈15、设施飞虫10、其他38，无跨来源合并。
4. 员工签名草稿刷新后可恢复，确认后形成服务内容快照。
5. 客户报告预览在可见页面累计至少5秒后，才开放主动阅读确认。
6. 离线可保存双方签字，发布操作不可用。
7. 模拟PDF生成失败时不产生归档报告，数据继续保留。
8. 重试或连续点击只产生一个当前版本的归档记录，7条未关闭风险继续保留。
9. 报告更正生成V2，清除新版本双签和阅读确认，V1内容不变；表单刷新后恢复。
10. 有客户虫情却没有关联处置来源时阻止签字。
11. 未检查设施必须填写原因，其旧捕获数量不加入当次汇总。
12. 门店搜索无匹配时展示空态。
