# 舍为思虫害治理 App · Vue 3 产品原型 V1.0

根据既有20页员工端白模，按用户提供的《舍为思智慧科技网站设计提示词》应用品牌VI。每个页面提供独立 Vue 单文件组件、独立入口程序和可直接打开的 HTML 文件。

## 立即查看

- 双击 `独立原型/index.html` 查看页面目录，再进入任一页面。
- 每个 `独立原型/01-login.html` 至 `20-profile.html` 都内嵌 Vue 运行时、CSS、图标和Logo，无需联网、安装依赖或连接CDN即可显示和交互。
- 页面含手机预览、目录和业务注释。链接末尾加 `?screen=1` 可只显示手机页面；跨页导航会保留该模式。
- 页面内容可以滚动；底部主要操作固定显示。`页面预览/`中的PNG仅为首屏，完整字段以可操作HTML为准。

**推荐用本地HTTP服务评审完整流程**：各页共用同一域名下的浏览器存储。直接双击HTML时，浏览器对 `file://` 的存储共享行为不同，跨页资料可能无法互通。

## 运行与开发

需要 Node.js 22.12或以上版本。依赖版本已固定在 `package-lock.json`。

```sh
npm ci
npm run dev
```

打开终端显示的 `http://127.0.0.1:5173/`；页面HTML在 `pages/`，Vue源程序在 `src/pages/`。修改页面后由Vite更新预览。

编译全部独立HTML：

```sh
npm run build
npm run preview
```

本地成品预览地址：`http://127.0.0.1:4173/`。`preview`本身只使用Node内置模块，交付包已有HTML时无需先安装依赖。退出服务按 Ctrl+C。

只编译一个页面，例如工作台：

```sh
npm run build:page -- home
```

可选页面ID见 `页面文件对照.md`。若4173端口占用，可运行 `PROTOTYPE_PORT=4174 npm run preview`。所有服务仅监听本机。

## 文件结构

```text
src/pages/          20个独立Vue页面，使用<script setup>
src/entries/        20个页面入口，每页单独挂载Vue应用
src/components/     表单、签名、照片、报告等公共组件
src/composables/    本机演示状态、校验、版本及页面跳转
src/data/           页面目录、线性图标、脱敏示例数据
src/styles/         VI颜色变量和响应式样式
src/assets/         原始舍为思品牌Logo
pages/              20个开发入口HTML
独立原型/           20个自包含HTML与页面总览，可单独打开
页面预览/           20个首屏PNG与6页品牌效果总览
scripts/            单页编译和本地预览服务
```

这些是20个独立Vue应用入口，不是把既有HTML作为字符串注入Vue。页面共享公共组件与样式；业务页各自维护模板和交互。独立成品将每页需要的公共代码内联，以便单文件分发。

## 建议评审路径

1. 登录 → 工作台 → 任务 → 任务详情。
2. 签到 → 服务前确认 → 静态评估 → 设施点检 → 风险跟进 → 防治措施。
3. 总结检查 → 员工签字 → 客户报告预览至少5秒 → 主动确认已读 → 姓名与客户签字。
4. 同步中心 → 模拟发布 → 报告归档 → 新建更正版本并重新签字。

评审页顶部的“载入完整示例”会填充9处设施、7条风险及处置记录，可直接体验后半段流程；不会生成员工或客户签名。照片占位块明确标注“演示”。也可以选择本机 JPG、PNG、WebP 图片，每张不超过800KB。

顶部“联网演示 / 离线演示”切换模拟网络状态；同步中心“原型测试：同步异常”可模拟附件失败、PDF失败或任务改派。失败不会生成归档记录；选择正常结果后可体验重试。真实改派冲突的主管处理不在本原型中。

客户反馈15、设施飞虫10、其他38分别汇总。默认部分设施尚未检查，因此默认报告不会把待检查设施的示例数量计入当次合计；载入完整示例后才显示上述完整数据。

## 当前实现边界

这是员工端产品风格与交互评审原型，**未连接Java后端或MySQL，也未生成安卓安装包、管理后台或正式PDF**。

已实现：页面跳转、任务筛选、应急任务录入、新增设施和风险、表单编辑、本次照片、手写签名、签名前关键校验、阅读计时、模拟同步失败重试、内容快照及更正版本。内容、照片和签名保存在当前浏览器的localStorage中，刷新后可恢复；存储失败会明确提示。

演示简化：当前单账号、单浏览器；图片存储受浏览器额度限制；设施状态更改、跨任务风险台账及复杂多项处置尚未完整实现；风险等级为综合人工评定；定位和任务下载均为演示；离线签署没有生产级摘要、权限校验和密码学保证。服务端幂等、并发冲突、账号隔离、附件可靠上传、正式报告生成和后台统计仍以已有接口文档及Java/MySQL架构稿落地。

“导出演示记录”下载JSON；“分享服务报告”展示正式App调用安卓系统分享的说明，不发送文件。重置只清除本原型存储键 `sheweisi-pest-vue-prototype-v1`。示例数据不使用附件中的真人签名或客户照片。
